# Webhook Strategy — RAWAQA

**Status:** Not applicable for MVP

RAWAQA MVP uses **outbound-only** integrations (Website → Odoo, Website → SMS). No inbound webhooks are in scope.

**Future (Change Request):**
- Payment gateway callbacks (Paymob, Fawry)
- Odoo inbound inventory updates

If added, require: signature verification, idempotency keys, async processing, and dedicated endpoint documentation.
