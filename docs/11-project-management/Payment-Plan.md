# Payment Plan — RAWAQA

**Total Project Value:** 35,000 EGP

---

## Schedule

| # | Milestone | Percentage | Amount (EGP) | Trigger |
|---|-----------|------------|-------------:|---------|
| 1 | Project start | 40% | **14,000** | Signed Scope of Work + kickoff meeting |
| 2 | Major milestone | 30% | **10,500** | Backend API, database, and admin dashboard complete and demonstrated on staging |
| 3 | Final delivery | 30% | **10,500** | Production deployment, UAT sign-off, documentation handover |
| | **Total** | **100%** | **35,000** | |

---

## Milestone 2 — Acceptance Criteria

The major milestone payment is due when the client can verify on **staging**:

- [ ] Admin login and dashboard accessible  
- [ ] Create/edit/delete product in admin → visible on shop  
- [ ] Customer can add to cart and complete checkout (Odoo/SMS may follow in next phase)  
- [ ] Order stored in database with correct totals  
- [ ] API documentation delivered  

---

## Milestone 3 — Acceptance Criteria

Final payment is due when:

- [ ] Production site live on client domain with SSL  
- [ ] End-to-end order: website → Odoo → SMS verified  
- [ ] UAT checklist completed and signed  
- [ ] Documentation pack handed over  
- [ ] Training/walkthrough completed (1 session)  

---

## Payment Terms

- Payments via bank transfer or agreed method  
- Invoice issued per milestone  
- Work pauses if payment delayed > 7 business days (per contract)  
- Scope changes billed separately via Change Request
