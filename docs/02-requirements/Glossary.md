# Glossary — RAWAQA

| Term | Definition |
|------|------------|
| **SPA** | Single Page Application — one HTML shell, JS route switching |
| **PDP** | Product Detail Page (`#page-product`) |
| **COD** | Cash on Delivery — payment on receipt |
| **EGP** | Egyptian Pound — sole currency |
| **Odoo** | Open-source ERP used for order fulfillment |
| **SKU** | Stock Keeping Unit — unique variant identifier |
| **JWT** | JSON Web Token — API authentication bearer token |
| **RWQ-** | Order number prefix (e.g., RWQ-10482) |
| **UAT** | User Acceptance Testing — client verification before sign-off |
| **CR** | Change Request — formal scope change process |
| **MVP** | Minimum Viable Product — launch scope |
| **ERP** | Enterprise Resource Planning (Odoo) |
| **RTL** | Right-to-left text direction for Arabic |
| **i18n** | Internationalization — multi-language content |
| **Integration Required** | In commercial scope but not yet built |
| **Partial** | UI or logic exists but incomplete |
